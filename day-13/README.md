# Dia 13 — Day 13: Exercício com HAVING para filtrar grupos de dados

Trilha: SQL  
Nível: intermediário  
Tema: HAVING

## Objetivo

Praticar o uso do HAVING para filtrar grupos após a agregação de dados

## Conceito

O HAVING é usado para filtrar grupos criados com GROUP BY. Diferente do WHERE, ele atua sobre resultados de agregação como SUM, COUNT ou AVG. Este exercício usa um cenário de vendas para ilustrar a aplicação prática.

## Desafio

Crie uma consulta que mostre os produtos com total de vendas acima de 1000 reais, usando HAVING para filtrar os grupos.

## Pontos principais

- Diferença entre WHERE e HAVING
- Filtrar grupos com HAVING
- Agregação com SUM e HAVING
