# Dia 16 — Day 16: Uso do CASE para categorização condicional

Trilha: SQL  
Nível: intermediário  
Tema: CASE

## Objetivo

Praticar a utilização do CASE para criar lógica condicional em consultas SQL, combinando com agrupamento e funções de agregação.

## Conceito

O CASE permite definir regras de categorização dinâmica. Vamos usar ele para calcular descontos baseados em valores de venda e região, agrupando os resultados por região.

## Desafio

Crie uma consulta que calcule o total de vendas com descontos aplicados, categorizando os descontos por região usando CASE. Mostre o total por região e o desconto total aplicado.

## Pontos principais

- Uso do CASE para lógica condicional
- Integração com GROUP BY e funções de agregação
- Cálculo de valores com base em regras dinâmicas

## Verificação

- Arquivos verificados estruturalmente; nenhum validador automático específico foi executado.
