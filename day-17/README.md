# Dia 17 — Day 17: Criando e usando views para simplificar consultas complexas

Trilha: SQL  
Nível: intermediário  
Tema: Views

## Objetivo

Praticar a criação de views para encapsular consultas complexas e reutilizáveis

## Conceito

Views são como tabelas virtuais que encapsulam consultas SQL. Elas permitem simplificar consultas repetitivas e proteger a lógica de acesso a dados. Neste exercício, você criará uma view que combina dados de múltiplas tabelas e usará ela para relatórios.

## Desafio

Crie uma view que exiba o nome do cliente, o total de pedidos e o valor médio por pedido, agrupando por cliente. Use a view para exibir os resultados.

## Pontos principais

- Entender a sintaxe CREATE VIEW
- Combinar consultas complexas em views
- Usar views para relatórios e análise
