# Dia 24 — Day 24: Constraints em SQL

Trilha: SQL  
Nível: avançado  
Tema: Constraints

## Objetivo

Praticar a criação de tabelas com restrições de integridade (NOT NULL, UNIQUE, CHECK, DEFAULT) e entender sua aplicação prática.

## Conceito

Crie um esquema de banco de dados para uma biblioteca com tabelas Books, Authors e Publishers. Adicione restrições como NOT NULL, UNIQUE, CHECK e DEFAULT. Teste inserções válidas e inválidas para verificar comportamento.

## Desafio

Implemente restrições em tabelas de livros, autores e editoras. Inclua validações para ano de publicação, nome de autor e código de país. Teste inserções com dados inválidos para observar erros de integridade.

## Pontos principais

- Diferença entre NOT NULL e UNIQUE
- Aplicação de CHECK para validação de dados
- Uso de DEFAULT para valores padrão
- Como restrições garantem integridade de dados

## Verificação

- Arquivos verificados estruturalmente; nenhum validador automático específico foi executado.
