# Dia 14 — Day 14: Funções de agregação

Trilha: SQL  
Nível: intermediário  
Tema: Funções de agregação

## Objetivo

Praticar o uso de funções de agregação para resumir dados em consultas SQL

## Conceito

As funções de agregação resumem dados em grupos. Vamos usar COUNT, SUM, AVG, MAX e MIN para analisar um conjunto de dados de vendas.

## Desafio

Crie consultas que calculem: total de vendas por produto, média de preços, quantidade de itens vendidos e valor máximo de uma venda.

## Pontos principais

- Uso de COUNT, SUM, AVG, MAX e MIN
- Combinar funções de agregação com GROUP BY
- Interpretação de resultados de consultas resumidas
