# Dia 01 — SELECT básico

Trilha: SQL  
Nível: iniciante  
Tema: SELECT básico

## Objetivo

Entender a sintaxe básica do SELECT para recuperar dados de uma tabela.

## Conceito

Crie uma tabela chamada 'funcionarios' com colunas id, nome, departamento e salario. Insira 3 registros. Escreva consultas para: 1) Selecionar todos os funcionários, 2) Selecionar apenas o nome e o departamento.

## Desafio

Implemente as consultas SQL para recuperar os dados conforme solicitado.

## Pontos principais

- Sintaxe SELECT
- Recuperação de dados
- Estrutura de tabelas
