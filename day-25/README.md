# Dia 25 — Análise de Planos de Execução com EXPLAIN

Trilha: SQL  
Nível: avançado  
Tema: Planos de execução

## Objetivo

Entender como analisar e otimizar consultas usando planos de execução, identificando operações como tabelas de junção, filtros e ordenação.

## Conceito

Usaremos EXPLAIN para visualizar como o motor de banco de dados executa consultas. Isso revela operações como junções, filtros e ordenação, ajudando a identificar gargalos de performance.

## Desafio

Crie uma consulta que retorne clientes com pedidos acima de 1000, ordenados por data, e analise seu plano de execução. Sugerir melhorias com base no plano.

## Pontos principais

- Compreender a estrutura de um plano de execução
- Identificar operações de junção e filtros
- Reconhecer custos de operações como ordenação
- Aplicar melhorias com base no plano
