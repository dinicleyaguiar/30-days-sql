# Dia 30 — Análise de Vendas com CTEs e Funções de Janela

Trilha: SQL  
Nível: avançado  
Tema: Projeto final SQL

## Objetivo

Criar uma consulta complexa que analisa dados de vendas usando CTEs, funções de janela e subconsultas para calcular métricas como valor total por região, média de pedidos e classificação de clientes.

## Conceito

Este exercício combina CTEs para estruturar a análise, funções de janela para classificação e subconsultas para filtragem. A consulta deve retornar métricas agregadas com contexto hierárquico.

## Desafio

Implementar uma consulta que calcule o valor total de vendas por região, identifique os 10 clientes com maior volume de compras e mostre a média de valor por pedido para cada região, usando CTEs e funções de janela.

## Pontos principais

- Uso de CTEs para organizar consultas complexas
- Funções de janela para classificação e agregação
- Subconsultas para filtragem de dados
- Interpretação de planos de execução com EXPLAIN

## Verificação

- Arquivos verificados estruturalmente; nenhum validador automático específico foi executado.
