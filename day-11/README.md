# Dia 11 — Day 11: Exercício de JOIN com tabelas de clientes e pedidos

Trilha: SQL  
Nível: intermediário  
Tema: JOIN

## Objetivo

Praticar a utilização de JOIN para combinar dados de duas tabelas relacionadas

## Conceito

Crie duas tabelas: 'clientes' e 'pedidos'. A tabela 'pedidos' deve ter uma chave estrangeira referenciando 'clientes'. Execute uma consulta que retorne todos os pedidos com o nome do cliente associado. Adicione uma nota explicando a diferença entre INNER JOIN e LEFT JOIN.

## Desafio

Ajuste a consulta para mostrar apenas pedidos com valor acima de 100 reais, mantendo a relação com os clientes.

## Pontos principais

- Entender como combinar dados de tabelas relacionadas
- Praticar diferentes tipos de JOIN
- Aprender a filtrar resultados com condições em JOINs
