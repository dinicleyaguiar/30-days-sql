# Dia 21 — CTEs para análise hierárquica

Trilha: SQL  
Nível: avançado  
Tema: CTEs

## Objetivo

Praticar a criação de CTEs para analisar relações hierárquicas em dados

## Conceito

CTEs são úteis para estruturar consultas complexas. Nesse exercício, você analisará uma hierarquia de funcionários para encontrar a cadeia de comandos.

## Desafio

Dado um banco de dados com uma tabela de funcionários, crie uma consulta que mostre a cadeia de comandos de um funcionário específico até o CEO.

## Pontos principais

- Como estruturar uma CTE recursiva
- Como lidar com hierarquias de dados
- Como usar CTEs para evitar repetição de consultas
