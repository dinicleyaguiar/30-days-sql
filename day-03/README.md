# Dia 03 — Ordenando resultados com ORDER BY

Trilha: SQL  
Nível: iniciante  
Tema: ORDER BY

## Objetivo

Aprender a ordenar resultados de consultas SQL usando a cláusula ORDER BY.

## Conceito

A cláusula ORDER BY permite organizar os resultados de uma consulta em ordem crescente (ASC) ou decrescente (DESC). Essa funcionalidade é essencial para relatórios e análise de dados.

## Desafio

Crie consultas que ordenem os registros da tabela 'produtos' por:
1. Preço em ordem crescente
2. Estoque em ordem decrescente
3. Nome em ordem alfabética e, em caso de empate, por preço em ordem decrescente

## Pontos principais

- Uso da cláusula ORDER BY
- Ordem crescente e decrescente
- Ordenação por múltiplas colunas

## Verificação

- Arquivos verificados estruturalmente; nenhum validador automático específico foi executado.
