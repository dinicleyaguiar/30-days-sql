# Dia 09 — Chaves primárias e estrangeiras

Trilha: SQL  
Nível: iniciante  
Tema: Chaves primárias e estrangeiras

## Objetivo

Entender como chaves primárias e estrangeiras estabelecem relacionamentos entre tabelas.

## Conceito

Criaremos duas tabelas com relacionamento 1:N (um cliente pode ter múltiplos pedidos). A chave primária identifica registros únicos e a chave estrangeira vincula registros entre tabelas.

## Desafio

Crie tabelas 'clientes' e 'pedidos' com relacionamento. Insira dados válidos e tente inserir um pedido com cliente inexistente para verificar a restrição de chave estrangeira.

## Pontos principais

- Chave primária: identificador único de uma tabela
- Chave estrangeira: vincula registros entre tabelas
- Restrição de integridade referencial
- Como o SQL trata violações de relacionamento
