# Dia 05 — Inserindo dados com INSERT

Trilha: SQL  
Nível: iniciante  
Tema: INSERT

## Objetivo

Aprender a adicionar registros em uma tabela usando o comando INSERT

## Conceito

O INSERT permite adicionar novos registros em uma tabela. É essencial entender a estrutura da tabela para inserir dados corretamente. Vamos criar uma tabela de clientes e inserir dados nela.

## Desafio

Crie uma tabela 'clientes' com as colunas nome, email, data_nascimento e cidade. Insira três registros diferentes usando INSERT. Teste se os dados foram salvos com SELECT.

## Pontos principais

- Sintaxe do INSERT INTO
- Inserção de um único registro
- Inserção de múltiplos registros em uma única instrução
- Importância de manter a ordem dos valores
