# Dia 27 — Modelagem Relacional: Criação de Esquema de Banco de Dados

Trilha: SQL  
Nível: avançado  
Tema: Modelagem relacional

## Objetivo

Criar um esquema relacional para um sistema de gestão escolar com tabelas de alunos, cursos e matrículas, incluindo restrições de integridade.

## Conceito

Você deve modelar um banco de dados para uma escola com as seguintes entidades: Alunos, Cursos e Matrículas. Relacione-as com chaves primárias e estrangeiras, garantindo que as relações sejam corretas e que não haja duplicidade em matrículas.

## Desafio

Implemente as tabelas com restrições adequadas para evitar dados inconsistentes. Inclua exemplos de dados de teste e consultas para verificar as relações.

## Pontos principais

- Modelagem de entidades relacionadas
- Uso de chaves primárias e estrangeiras
- Prevenção de duplicidade em relações muitos-para-muitos

## Verificação

- Arquivos verificados estruturalmente; nenhum validador automático específico foi executado.
