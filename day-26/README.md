# Dia 26 — Day 26: Otimização de Consultas com Índices e Estrutura

Trilha: SQL  
Nível: avançado  
Tema: Otimização de consultas

## Objetivo

Aprimore consultas lentas usando índices e reestruturação de queries

## Conceito

Optimize uma consulta que realiza varredura completa em uma tabela grande. Use índices e reescreva a query para evitar operações desnecessárias.

## Desafio

Crie uma consulta que retorne vendas de produtos da categoria 'eletrônicos' com os campos: data, valor e quantidade. Aplique otimizações para reduzir o tempo de execução.

## Pontos principais

- Uso de índices para evitar varreduras completas
- Seleção de colunas específicas em vez de '*'
- Reestruturação de queries para aproveitar índices
- Análise de planos de execução com EXPLAIN

## Verificação

- Arquivos verificados estruturalmente; nenhum validador automático específico foi executado.
