# Dia 28 — Auditoria de Dados: Identificação de Duplicatas

Trilha: SQL  
Nível: avançado  
Tema: Auditoria de dados

## Objetivo

Praticar a identificação e correção de duplicatas em uma tabela usando consultas SQL.

## Conceito

Auditar dados envolve verificar inconsistências como duplicatas. Neste exercício, identificaremos registros duplicados em uma tabela de funcionários e corrigiremos os dados.

## Desafio

Crie uma consulta que encontre funcionários com o mesmo nome e CPF, e depois remova as duplicatas mantendo apenas o registro mais recente.

## Pontos principais

- Uso de funções de agregação para identificar duplicatas
- Manipulação de subconsultas para filtragem
- Uso de cláusulas ORDER BY e LIMIT para selecionar registros específicos

## Verificação

- Arquivos verificados estruturalmente; nenhum validador automático específico foi executado.
