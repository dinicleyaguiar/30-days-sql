# Dia 22 — Day 22: Funções de Janela para Análise de Dados

Trilha: SQL  
Nível: avançado  
Tema: Window functions

## Objetivo

Praticar o uso de funções de janela para classificação e cálculo acumulado em consultas SQL

## Conceito

Crie uma consulta que mostre a classificação de vendas por cliente e o total acumulado de cada cliente. Use funções de janela como ROW_NUMBER(), RANK() e SUM() com cláusula OVER().

## Desafio

Implemente uma solução que: 1) Crie tabelas temporárias com dados de vendas e clientes 2) Calcule a classificação de cada venda por cliente 3) Mostre o total acumulado de vendas por cliente

## Pontos principais

- Entender como funções de janela operam em conjuntos de dados
- Aprender a usar cláusulas PARTITION BY e ORDER BY em funções de janela
- Praticar cálculos acumulados com SUM() e frames de janela
