# Dia 04 — Limitando e paginando resultados

Trilha: SQL  
Nível: iniciante  
Tema: LIMIT e OFFSET

## Objetivo

Aprender a usar LIMIT e OFFSET para controlar quantos registros são retornados e como paginar resultados.

## Conceito

Usamos LIMIT para definir o número máximo de registros a serem retornados e OFFSET para pular um número específico de registros. Isso é útil para implementar listagens paginadas em aplicações.

## Desafio

Crie uma consulta que retorne os 5 primeiros livros ordenados por título, e outra que retorne os 5 livros a partir da posição 6 (página 2 de 2 itens por página).

## Pontos principais

- LIMIT define o número máximo de registros a serem retornados
- OFFSET define a posição inicial dos registros
- Combinar com ORDER BY para garantir consistência
- Uso prático em listagens paginadas
