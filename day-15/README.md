# Dia 15 — Subqueries: Filtrando dados com consultas aninhadas

Trilha: SQL  
Nível: intermediário  
Tema: Subqueries

## Objetivo

Aprender a usar subqueries para filtrar dados em consultas SQL

## Conceito

Subqueries são consultas aninhadas que retornam valores usados em condições. Elas são úteis para comparar dados entre tabelas ou filtrar resultados com base em critérios dinâmicos.

## Desafio

Crie uma consulta que retorne todos os funcionários cujo salário é maior que a média salarial da empresa. Use uma subquery para calcular a média salarial.

## Pontos principais

- Uso de subqueries em cláusulas WHERE
- Agregação de dados com funções como AVG()
- Estrutura de consultas aninhadas
