# Dia 06 — Atualizando registros com UPDATE

Trilha: SQL  
Nível: iniciante  
Tema: UPDATE

## Objetivo

Aprender a modificar dados existentes em uma tabela usando o comando UPDATE.

## Conceito

O UPDATE permite alterar valores em registros específicos. É essencial usar WHERE para evitar modificar todos os registros. Sempre valide a query antes de executar para evitar erros.

## Desafio

Atualize o e-mail e o status de um cliente específico na tabela 'clientes'.

## Pontos principais

- Sintaxe do UPDATE
- Uso de WHERE para seleção específica
- Riscos de omitir WHERE

## Verificação

- Arquivos verificados estruturalmente; nenhum validador automático específico foi executado.
