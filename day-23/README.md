# Dia 23 — Day 23: Transações e Integridade de Dados

Trilha: SQL  
Nível: avançado  
Tema: Transações

## Objetivo

Implementar transações para garantir operações atômicas em um sistema bancário

## Conceito

Criaremos um sistema de transferência de fundos que utiliza transações para manter a integridade dos dados. O exercício envolve criar tabelas, implementar uma procedure armazenada e testar transações com commit e rollback.

## Desafio

Implementar uma transferência de fundos entre contas que garante que as operações sejam atômicas e reversíveis em caso de erro.

## Pontos principais

- Uso de BEGIN, COMMIT e ROLLBACK em transações
- Manipulação de erros em operações de banco de dados
- Segurança de dados em operações financeiras
- Gerenciamento de consistência em sistemas distribuídos
