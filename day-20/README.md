# Dia 20 — Day 20: Transações e Integridade de Dados

Trilha: SQL  
Nível: intermediário  
Tema: Mini projeto intermediário

## Objetivo

Praticar o uso de transações para garantir a integridade de dados em operações complexas.

## Conceito

Crie um banco de dados para um sistema de vendas com tabelas de usuários, pedidos e itens. Implemente uma transação que insira um novo usuário, crie um pedido e adicione itens ao pedido. Se qualquer operação falhar, a transação deve ser revertida.

## Desafio

Garanta que a transação mantenha a consistência dos dados em todas as etapas, mesmo que uma operação falhe.

## Pontos principais

- Uso de transações para operações múltiplas
- Integridade referencial com chaves estrangeiras
- Manipulação de erros em operações de banco de dados

## Verificação

- Arquivos verificados estruturalmente; nenhum validador automático específico foi executado.
