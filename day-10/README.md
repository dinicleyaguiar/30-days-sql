# Dia 10 — Revisão prática com banco de dados relacional

Trilha: SQL  
Nível: iniciante  
Tema: Revisão prática do nível iniciante

## Objetivo

Revisar conceitos básicos criando um esquema de banco de dados e consultando dados relacionados

## Conceito

Vamos criar um esquema com tabelas relacionadas e praticar consultas que combinam múltiplos conceitos aprendidos

## Desafio

Crie um banco de dados para um sistema de pedidos com tabelas de clientes e pedidos, depois responda consultas que relacionem os dados

## Pontos principais

- Uso de CREATE TABLE com restrições
- Relacionamento entre tabelas com chaves estrangeiras
- Consultas JOIN para combinar dados
- Aplicação de filtros e ordenação em consultas complexas
