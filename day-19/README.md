# Dia 19 — Day 19: Normalização de Banco de Dados

Trilha: SQL  
Nível: intermediário  
Tema: Normalização

## Objetivo

Praticar a normalização de tabelas para reduzir redundância e melhorar a integridade dos dados.

## Conceito

Vamos normalizar uma tabela denormalizada de produtos que contém dados repetidos. Criaremos tabelas separadas para categorias e produtos, e escreveremos consultas para recuperar os dados normalizados.

## Desafio

Normalizar a tabela de produtos e escrever consultas para recuperar os dados com as relações estabelecidas.

## Pontos principais

- Entender a diferença entre tabelas denormalizadas e normalizadas
- Criar estruturas de tabelas com chaves primárias e estrangeiras
- Usar JOINs para recuperar dados relacionados

## Verificação

- Arquivos verificados estruturalmente; nenhum validador automático específico foi executado.
