# Dia 07 — Exclusão de Registros com DELETE

Trilha: SQL  
Nível: iniciante  
Tema: DELETE

## Objetivo

Praticar a remoção de dados com o comando DELETE, com foco em segurança e precisão.

## Conceito

O DELETE é usado para remover registros de uma tabela. É essencial usar WHERE para evitar exclusões acidentais. Este exercício aborda a remoção de dados com condições específicas.

## Desafio

Você precisa excluir registros de uma tabela chamada 'produtos' com base em critérios específicos. Certifique-se de não remover dados importantes acidentalmente.

## Pontos principais

- Uso do comando DELETE com WHERE para filtrar registros
- Importância de validar consultas antes de executar exclusões
- Consequências de omitir condições em DELETE
