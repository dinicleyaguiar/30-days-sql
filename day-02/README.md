# Dia 02 — Filtrando dados com WHERE

Trilha: SQL  
Nível: iniciante  
Tema: WHERE

## Objetivo

Praticar a utilização do WHERE para filtrar registros em consultas SQL

## Conceito

Agora que sabemos selecionar dados, vamos aprender a filtrar esses dados com condições. O WHERE é usado para especificar critérios de busca.

## Desafio

Crie uma consulta que retorne todos os produtos com preço maior que 50 e categoria 'eletrônicos' usando WHERE.

## Pontos principais

- Uso do WHERE para filtrar registros
- Operadores de comparação (> , < , =)
- Combinação de condições com AND

## Verificação

- Arquivos verificados estruturalmente; nenhum validador automático específico foi executado.
