# Dia 12 — Agrupando dados com GROUP BY

Trilha: SQL  
Nível: intermediário  
Tema: GROUP BY

## Objetivo

Praticar a utilização do GROUP BY para resumir dados em categorias

## Conceito

O GROUP BY é usado para agrupar linhas com valores semelhantes em colunas. Combinado com funções agregadas como SUM, COUNT ou AVG, permite resumir dados de forma eficiente.

## Desafio

Crie uma tabela 'vendas' com colunas 'produto', 'categoria' e 'valor'. Insira dados de vendas e calcule o total de vendas por categoria.

## Pontos principais

- Uso de GROUP BY para agrupar dados
- Agregação com SUM para calcular totais
- Interpretação de resultados agrupados
