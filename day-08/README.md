# Dia 08 — Tipos de dados em SQL

Trilha: SQL  
Nível: iniciante  
Tema: Tipos de dados

## Objetivo

Praticar a criação de tabelas com diferentes tipos de dados e consultas básicas

## Conceito

Crie uma tabela chamada 'produtos' com os seguintes campos: id (INT), nome (VARCHAR), preco (DECIMAL), data_cadastro (DATE), disponivel (BOOLEAN). Insira 3 registros e consulte todos os registros. Em seguida, consulte apenas os produtos disponíveis com preço acima de 100.

## Desafio

Adicione um novo campo 'categoria' (VARCHAR) à tabela e atualize os registros existentes com categorias apropriadas.

## Pontos principais

- Entender os principais tipos de dados SQL
- Criar tabelas com estrutura definida
- Inserir e consultar dados com diferentes tipos
- Modificar estrutura de tabelas
